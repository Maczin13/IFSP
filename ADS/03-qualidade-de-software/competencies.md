# Competências demonstradas — Qualidade de Software

Demonstrei análise de requisitos, particionamento de equivalência, valores-limite, desenho de testes negativos, isolamento por fixtures, parametrização, verificação de exceções de negócio e uso de `Decimal` para valores monetários. O código separa validação, regras de cupom, estoque e cálculo do resultado.

A evidência é composta por `processador_vendas.py`, dados JSON, dez testes automatizados e logs de execução. As limitações estão explicitadas: não há integração real de pagamento, sistema produtivo ou dados de clientes.
