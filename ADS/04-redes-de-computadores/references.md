# Referências anotadas

- Kurose, James F.; Ross, Keith W. *Computer Networking: A Top-Down Approach*, 8th ed., Pearson, 2021 — aplicações, transporte, sockets, confiabilidade e congestionamento.
- IETF RFC 9110, *HTTP Semantics*: https://www.rfc-editor.org/rfc/rfc9110 — métodos, status e semântica HTTP.
- IETF RFC 9112, *HTTP/1.1*: https://www.rfc-editor.org/rfc/rfc9112 — framing, mensagens e conexões HTTP/1.1.
- IETF RFC 9293, *Transmission Control Protocol*: https://www.rfc-editor.org/rfc/rfc9293 — estabelecimento, confiabilidade e encerramento TCP.
- Python `socket` documentation: https://docs.python.org/3/library/socket.html — API de sockets usada no código.
- Python `threading` documentation: https://docs.python.org/3/library/threading.html — modelo de concorrência do laboratório.
- IETF RFC 8446, *TLS 1.3*: https://www.rfc-editor.org/rfc/rfc8446 — referência para a limitação de tráfego sem criptografia.
