# Referências anotadas

- NISTIR 8259A, *IoT Device Cybersecurity Capability Core Baseline*: https://csrc.nist.gov/pubs/ir/8259/a/final — identidade, configuração, proteção de dados, controle de acesso, atualização e estado de segurança.
- OASIS MQTT Version 5.0: https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html — referência para extensão de mensageria, não uma integração alegada no laboratório.
- Python `dataclasses`: https://docs.python.org/3/library/dataclasses.html — modelagem de leituras, configuração e decisões imutáveis.
- Python `logging`: https://docs.python.org/3/library/logging.html — logs estruturados de decisões e falhas.
- pytest parametrization/fixtures: https://docs.pytest.org/en/stable/how-to/parametrize.html — desenho da suíte automatizada.
