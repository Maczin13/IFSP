# Referências anotadas

- FastAPI documentation: https://fastapi.tiangolo.com/ — rotas, dependências, Pydantic e OpenAPI.
- OpenAPI Specification 3.1: https://spec.openapis.org/oas/v3.1.0 — contrato de descrição de APIs HTTP.
- Pydantic documentation: https://docs.pydantic.dev/ — validação e serialização de modelos.
- OWASP API Security Top 10 2023: https://owasp.org/API-Security/editions/2023/en/0x11-t10/ — autorização, autenticação, consumo de recursos e configuração.
- RFC 9110, HTTP Semantics: https://www.rfc-editor.org/rfc/rfc9110 — métodos e códigos de status.
