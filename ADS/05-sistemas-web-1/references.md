# Referências anotadas

- Flask Quickstart e Testing: https://flask.palletsprojects.com/en/stable/quickstart/ e https://flask.palletsprojects.com/en/stable/testing/ — ciclo de rotas, request, response e client de testes.
- IETF RFC 9110, HTTP Semantics: https://www.rfc-editor.org/rfc/rfc9110 — métodos, status e redirecionamentos.
- Python sqlite3: https://docs.python.org/3/library/sqlite3.html — DB-API, transações e queries parametrizadas.
- W3C WCAG 2.2: https://www.w3.org/TR/WCAG22/ — critérios de labels, teclado, foco e mensagens de status.
- OWASP Input Validation Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/Input_Validation_Cheat_Sheet.html — validação server-side e limites.
