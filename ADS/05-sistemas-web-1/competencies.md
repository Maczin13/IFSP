# Competências demonstradas — Sistemas Web 1

Demonstrei ciclo request/response HTTP, roteamento Flask, formulário HTML, validação server-side, redirecionamento 303, templates Jinja, persistência relacional SQLite, queries parametrizadas, fixture de aplicação, testes de integração com cliente HTTP e critérios selecionados de acessibilidade WCAG.

A evidência está em `app.py`, `templates/index.html`, `tests/test_web.py` e no log de execução. As limitações de autenticação, CSRF e escala permanecem documentadas como fora do escopo.
